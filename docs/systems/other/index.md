Pe langa modulele principale de WeaponSkins si Casino, serverul **WildFire.ro** integreaza o colectie extinsa de sisteme auxiliare menite sa imbunatateasca gameplay-ul competitiv, transparenta meciurilor si experienta audio-vizuala a fiecarui jucator.

---

> [!NOTE]
> Toate utilitatile sunt configurabile individual prin comenzile specifice sau prin meniul central de preferinte `!settings`.

## Sinteza Comenzilor Rapide din Aceasta Sectiune

| Comanda | Sintaxa Oficiala | Descriere & Rol |
| :--- | :--- | :--- |
| `!rank` | `!rank` | Afiseaza pozitia ta curenta in clasament, ELO si numarul de kill-uri |
| `!top` | `!top` | Deschide clasamentul celor mai buni jucatori de pe server |
| `!faceitinfo` | `!faceitinfo` | Afiseaza statisticile si nivelul FACEIT sincronizat |
| `!missions` | `!missions` | Deschide lista de misiuni active pentru castig de Phoenix Coins |
| `!mvp` | `!mvp` | Deschide selectorul melodiilor de MVP Anthem |
| `!ht` | `!ht` | Activeaza/dezactiveaza ascunderea coechipierilor (FPS boost) |
| `!rtv` | `!rtv` | Voteaza pentru schimbarea hartii curente (Rock The Vote) |
| `!settings` | `!settings` | Panoul de configurare a tuturor preferintelor tale de client |
| `!pm` | `!pm [jucator] [mesaj]` | Trimite un mesaj privat unui jucator |
| `!sm` | `!sm` | Meniul de sunete Sank Sounds pentru divertisment |
