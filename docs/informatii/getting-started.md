Bine ai venit pe **WildFire.ro**! Pentru a avea acces complet la toate facilitatile comunitatii, a primi recompense zilnice si a-ti asigura contul, urmeaza acest ghid rapid de initiere.

---

## Conectare Rapida pe Server

Poti intra pe server deschizand consola in joc (tasta `~` sau `\`) si ruland comanda:

```bash
connect cs2.wildfire.ro
```

> [!NOTE]
> Serverul ruleaza pe tickrate optimizat si accepta toti jucatorii cu conturi Steam valide si jocul CS2 actualizat.

---

## Verificare si Asociere Cont (Steam ➔ Discord)

Asocierea contului de Steam cu serverul de Discord iti deblocheaza rolul dedicat de **Membru Verificat**, accesul la canalele de suport si protectia datelor de progres.

<Steps>

<Step title="Conecteaza-te pe Server">

Intra pe serverul de CS2 tastand `connect cs2.wildfire.ro` in consola jocului.

</Step>

<Step title="Genereaza Codul Unic de Securitate">

Odata intrat pe server, tasteaza comanda `!link` in chat-ul public.

</Step>

<Step title="Copiaza Codul Generat">

Serverul iti va afisa in chat si in consola un cod unic de asociere format din 6 caractere (valabil timp de 10 minute).

</Step>

<Step title="Valideaza pe Discord">

Acceseaza serverul oficial de [Discord WildFire](https://discord.gg/wildfire), navigheaza pe canalul `#verificare` si ruleaza comanda:

```bash
/verify [codul_tau]
```

</Step>

</Steps>

> [!TIP]
> Dupa finalizarea verificarii, vei primi automat rolul de jucator verificat pe Discord si vei avea acces la giveaway-uri exclusive si anunturi prioritare.

## Comenzi Esentiale pentru Jucatori

Iata lista principalelor comenzi pe care le poti folosi in chat pentru a naviga prin sistemele serverului:

| Comanda | Descriere & Utilizare |
| :--- | :--- |
| `!ws` | Meniul central WeaponSkins — personalizeaza arme, cutite, manusi si agenti |
| `!inv` | Deschide inventarul personal de skin-uri si iteme |
| `!cases` | Deschide cutii si lazi cu skin-uri direct in timpul meciului |
| `!shop` | Magazinul cosmetic pentru chat tags, culori, tracers si efecte |
| `!eco` | Afiseaza balanta curenta de Credite si Phoenix Coins |
| `!eco pay [jucator] [suma] [moneda]` | Transfera `credits` sau `phoenix_coins` catre un alt jucator |
| `!rl` | Deschide masa de Ruleta pentru pariuri |
| `!sl` | Deschide jocul de Slots / Pacanele |
| `!bb [suma]` | Joaca Barbut / Zaruri cu suma specificata |
| `!mvp` | Personalizeaza melodia si animatia de sfarsit de runda (MVP Anthem) |
| `!battlepass` | Vizualizeaza progresia si recompensele sezonului curent |
| `!missions` | Misiunile active pentru castigarea rapida de Phoenix Coins |
| `!sm` | Sank Sounds — meniul cu sunete si meme-uri audio redate in chat |
| `!rank` | Afiseaza nivelul de experienta, ELO-ul si pozitia in clasament |
| `!ht` | Hide Teammates — ascunde coechipierii pentru boost de FPS |
| `!settings` | Meniul de setari si preferinte personale pe server |
| `!rtv` | Voteaza pentru schimbarea hartii curente (Rock The Vote) |

> [!IMPORTANT]
> **WeaponSkins & Modele:** Toate skin-urile de arme, cutitele, manusile si skin-urile de personaj se configureaza **exclusiv din interfata `!ws`** (nu exista comenzi separate).
