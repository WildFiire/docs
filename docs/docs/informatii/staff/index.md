## Ierarhia Gradelor Administrative

Echipa de moderare WildFire este structurata ierarhic pe baza de meritocratie, activitate si responsabilitate:

| Grad Administrativ | Nivel Acces | Rol & Responsabilitati Principale |
| :--- | :--- | :--- |
| **Helper** | Nivel de Baza | Asistenta directa jucatori pe chat/voice, sanctiuni usoare (max. 60m). |
| **Moderator** | Nivel Mediu | Solutionare sesizari pe `u@`, supraveghere spectate, sanctiuni extinse (max. 120m). |
| **Administrator** | Nivel Avansat | Solutionare cereri unban, investigatii avansate, aplicare banuri temporare/permanente. |
| **Supervizor** | Coordonare Staff | Evaluare activitate moderatori, supraveghere buna desfasurare pe server. |
| **Server Manager** | Conducere Server | Solutionare reclamatii, management aplicatii Helper, decizii structurale. |
| **Community Manager** | Management Comunitate | Coordonare globala comunitate, evenimente si politici administrative. |
| **Owner / Root** | Conducere Suprema | Administrare tehnica infrastructura, baze de date si securitate. |

## Protocoale Esentiale de Moderare

Fiecare membru al echipei trebuie sa respecte urmatoarele 3 standarde de aur:

* **1. Sesizari pe Chat-ul Administrativ (`u@`):**  
  Cand un jucator raporteaza un posibil trisator pe `u@`, treci imediat la modul Spectator pentru a verifica suspectul. Nu ignora chat-ul adminilor pentru a continua runda personala.

* **2. Dovezi Obligatorii (Demo / Video):**  
  Orice Ban Permanent acordat pentru cheat-uri trebuie documentat printr-o filmare/demo salvat in PC pentru minimum **7 zile**.

* **3. Comunicare & Lucru in Echipa:**  
  Conflictele sau neclaritatile dintre moderatori nu se discuta niciodata pe chat-ul public, ci exclusiv pe canalele private de Discord sau direct cu un Server Manager.

> [!TIP]
> Pentru a fi mereu la curent cu schimbarile de proceduri, verifica zilnic anunturile interne de pe serverul oficial de [Discord WildFire](https://discord.gg/wildfire).
