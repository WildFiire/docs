Magazinul **In-Game Shop (`!shop`)** este centrul cosmetic dedicat personalizarii stilului tau vizual pe serverul **WildFire.ro**. Aici poti cheltui **Creditele** acumulate prin simplul fapt ca joci pe server pentru a-ti colora chat-ul, a-ti seta tag-uri exclusive si a activa efecte vizuale speciale.

---

> [!NOTE]
> Toate cosmeticele achizitionate din magazinul `!shop` au o perioada de valabilitate de **7 zile** si pot fi reinnoite sau combinate oricand doresti.

## Comenzi Rapide de Magazin

* `!shop` — Deschide meniul grafic principal al magazinului.
* `!settag [text]` — Seteaza un prefix custom afisat inaintea numelui tau in chat.
* `!setnamecolor` — Deschide selectorul de culori pentru numele tau.
* `!eco` — Verifica balanta curenta de Credite si Phoenix Coins inainte de cumparare.

> [!TIP]
> Poti combina toate optiunile simultan: un **Tag auriu**, un **Nume cyan** si **Mesaje albe** pentru un profil vizual unic pe server!
